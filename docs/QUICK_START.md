# クイックスタートガイド

## 🚀 5分で始める議事録自動生成

このガイドでは、最短で議事録を生成する方法を説明します。

---

## ⚠️ 事前準備: VPN接続

**このアプリケーションはIP制限がかかっています。**

アクセスする前に、必ず**ジールのVPNに接続**してください。

---

## ステップ1: アカウント作成（初回のみ）

1. **ジールのVPNに接続**
2. https://main.d1iv2q5yh6oc7s.amplifyapp.com にアクセス
3. 「新規アカウントを作成」をクリック
4. メールアドレスとパスワードを入力
5. メールで届いた確認コードを入力

**所要時間: 2分**

**注意:** VPNに接続していないとアクセスできません

---

## ステップ2: ログイン

1. メールアドレスとパスワードを入力
2. 「サインイン」をクリック

**所要時間: 30秒**

---

## ステップ3: ファイルをアップロード

1. 「新規アップロード」ボタンをクリック
2. MP4ファイルを選択（またはドラッグ&ドロップ）
3. 「アップロード開始」をクリック

**所要時間: 1分**

---

## ステップ4: 処理を待つ

自動的に以下の処理が実行されます：

```
✅ アップロード完了
⏳ 文字起こし中... (5～30分)
⏳ 議事録生成中... (1～2分)
✅ 完了！
```

**処理時間: 会議の長さによる**
- 10分の会議 → 約5～10分
- 30分の会議 → 約15～30分
- 1時間の会議 → 約30～60分

**ヒント:** ページを閉じても処理は継続されます

---

## ステップ5: 議事録を確認

1. 「ジョブ一覧」をクリック
2. 完了したジョブをクリック
3. 「議事録を表示」をクリック

**所要時間: 30秒**

---

## ステップ6: 議事録を活用

### トピックの編集
- トピックの追加・編集・削除が可能
- ドラッグ&ドロップで順序変更
- 変更は自動保存されます

### AI検索機能
- 「議事録一覧」ページから自然言語で検索
- 例：「予算について話し合った会議は？」

### チャットQ&A
- 「チャット」ボタンをクリック
- 議事録の内容について質問可能
- AIが自動的に回答します

### ダウンロード
- 「ダウンロード」ボタンをクリック
- Markdown形式でダウンロード完了

**所要時間: 10秒**

---

## 🎉 完了！

これで議事録の自動生成が完了しました。

---

## 次のステップ

### より良い議事録を生成するために

1. **音声品質を向上させる**
   - 静かな環境で録音
   - マイクを話者に近づける
   - 背景ノイズを減らす

2. **適切なファイルサイズ**
   - 長時間の会議は分割することを検討
   - 2GB以下に収める

3. **効率的に使う**
   - 複数のファイルを連続してアップロード
   - 処理中に次の会議の準備
   - 定期的にダウンロードしてバックアップ

### トラブルシューティング

問題が発生した場合は、[ユーザーガイド](USER_GUIDE.md)の「トラブルシューティング」セクションを参照してください。

## よく使う機能

### ジョブ一覧の確認

```
トップページ → 「ジョブ一覧」
```

すべての処理状況を一覧で確認できます。

### 議事録の再表示

```
ジョブ一覧 → ジョブをクリック → 「議事録を表示」
```

過去の議事録をいつでも確認できます（90日間保存）。

### ログアウト

```
右上のメニュー → 「ログアウト」
```

## ヒント集

### 💡 処理時間を短縮する

- 短い会議から試す
- 音声のみのファイルを使用（動画より軽い）

### 💡 精度を向上させる

- 明瞭な音声で録音
- 話者が順番に話すようにする
- 会議の冒頭で参加者名を明示する

### 💡 効率的に使う

- 複数のファイルを連続してアップロード
- 処理中に次の会議の準備
- 定期的にダウンロードしてバックアップ
- AI検索で過去の議事録から情報を検索
