## 概要

このアプリケーションは、会議の録音・録画ファイルをアップロードするだけで、自動的に議事録を生成します。

### できること

- 🎤 **音声・動画ファイルのアップロード** - MP4形式の会議録音/録画をアップロード
- 📝 **自動文字起こし** - Amazon Transcribeで音声を自動的にテキスト化
- 🤖 **AI議事録生成** - Claude 3.5 Sonnetが議事録を自動作成
- 📊 **構造化された議事録** - 要約、議題、決定事項、アクションアイテムを整理
- 💾 **ダウンロード** - Markdown形式でダウンロード可能

### 対応ファイル形式

- **形式**: MP4
- **最大サイズ**: 2GB
- **推奨**: 音声が明瞭な録音・録画ファイル

## 初回ログイン

### 1. アカウント作成

初めて利用する場合は、アカウントを作成します。

1. アプリケーションURLにアクセス
2. 「新規アカウントを作成」をクリック
3. 以下の情報を入力：
   - **名前**（オプション）
   - **メールアドレス**
   - **パスワード**（8文字以上、大文字・小文字・数字を含む）
   - **パスワード（確認）**
4. 「アカウント作成」をクリック

### 2. メール確認

1. 登録したメールアドレスに確認コードが送信されます
2. メールを開いて6桁の確認コードをコピー
3. アプリの確認画面に確認コードを入力
4. 「確認」をクリック

### 3. ログイン

1. メールアドレスとパスワードを入力
2. 「サインイン」をクリック

## 議事録の作成

### ステップ1: ファイルのアップロード

1. ログイン後、「新規アップロード」ボタンをクリック
2. 「ファイルを選択」をクリックして、MP4ファイルを選択
   - または、ファイルをドラッグ&ドロップ
3. 「アップロード開始」をクリック

**ヒント:**
- ファイルサイズが大きい場合、アップロードに時間がかかります
- ドラッグ&ドロップでも簡単にアップロードできます

**今後の機能追加予定:**
- 会議タイトル、日時、参加者の入力機能（より詳細な議事録生成のため）

### ステップ2: 処理の待機

アップロード後、以下の処理が自動的に実行されます：

```
1. アップロード完了 ✅
   ↓
2. 文字起こし中 🎤 (数分～数十分)
   ↓
3. 議事録生成中 📝 (1～2分)
   ↓
4. 完了 ✅
```

**処理時間の目安:**
- 10分の会議: 約5～10分
- 30分の会議: 約15～30分
- 1時間の会議: 約30～60分

**注意:**
- ページを閉じても処理は継続されます
- 処理状況は「ジョブ一覧」から確認できます

### ステップ3: 進捗確認

1. 「ジョブ一覧」ページで処理状況を確認
2. ステータスが「完了」になるまで待機
3. 自動更新されるため、ページを開いたままにしておくと便利です

## 議事録の確認

### 議事録の表示

1. 「ジョブ一覧」から完了したジョブをクリック
2. 「議事録を表示」ボタンをクリック
3. 生成された議事録が表示されます

### 議事録の構成

生成される議事録には以下の情報が含まれます：

#### 1. 会議情報
- ジョブID
- ファイル名
- 処理日時

**今後追加予定:**
- 会議タイトル
- 開催日時
- 参加者

#### 2. 要約（Summary）
会議全体の簡潔なまとめ（2～3文程度）

#### 3. 決定事項（Decisions）
会議で決定された重要な事項
- 決定内容の説明
- タイムスタンプ（該当箇所）

#### 4. ネクストアクション（Next Actions）
今後実施すべきアクションアイテム
- アクションの説明
- 担当者（明示されている場合）
- 期限（明示されている場合）
- タイムスタンプ（該当箇所）

**注意:** 決定事項やアクションアイテムが明確でない場合は、空のリストになります。

### 議事録のダウンロード

1. 議事録表示画面で「ダウンロード」ボタンをクリック
2. Markdown形式（.md）でダウンロードされます
3. テキストエディタやMarkdownビューアで開けます

**ダウンロードしたファイルの活用方法:**
- Notion、Confluence、Slackなどに貼り付け
- Word、Googleドキュメントで編集
- GitHubのREADMEとして使用

## よくある質問

### Q1. どのような会議に適していますか？

**A:** 以下のような会議に最適です：
- 定例会議
- プロジェクト会議
- 打ち合わせ
- ブレインストーミング
- 研修・セミナー

**注意:** 機密性の高い会議の場合は、セキュリティポリシーを確認してください。

### Q2. 音声品質の要件は？

**A:** 以下の条件で最良の結果が得られます：
- ✅ 明瞭な音声
- ✅ 背景ノイズが少ない
- ✅ 話者が明確に発音している
- ❌ 複数人が同時に話している（精度が下がる）
- ❌ 音量が小さすぎる

### Q3. 日本語以外の言語に対応していますか？

**A:** 現在は日本語のみ対応しています。

### Q4. 生成された議事録を編集できますか？

**A:** アプリ内での編集機能はありません。ダウンロード後、お好みのエディタで編集してください。

### Q5. ファイルはどのくらい保存されますか？

**A:** 
- **入力ファイル（動画）**: 7日間
- **議事録**: 90日間

期限を過ぎると自動的に削除されます。重要な議事録は必ずダウンロードしてください。

### Q6. 複数のファイルを同時にアップロードできますか？

**A:** 現在は1つずつのアップロードのみ対応しています。

### Q7. 処理が失敗した場合は？

**A:** 以下を確認してください：
- ファイル形式がMP4か
- ファイルサイズが2GB以下か
- 音声が含まれているか

問題が解決しない場合は、管理者に連絡してください。

### Q8. コストはかかりますか？

**A:** 使用量に応じて以下のコストが発生します：
- 文字起こし: 約$0.024/分
- AI議事録生成: 約$0.05～0.10/会議

詳細は管理者にお問い合わせください。

## トラブルシューティング

### アプリケーションにアクセスできない

**症状:** URLにアクセスしても「接続できません」「アクセスが拒否されました」と表示される

**解決方法:**
1. **ジールのVPNに接続しているか確認**（最も多い原因）
2. VPN接続が確立されているか確認
3. VPN接続を一度切断して再接続
4. ブラウザのキャッシュをクリア
5. 別のブラウザで試す
6. VPN接続方法が不明な場合は、IT部門に連絡

**重要:** このアプリケーションはIP制限がかかっているため、VPN接続なしではアクセスできません。

### アップロードできない

**症状:** ファイルを選択してもアップロードボタンが押せない

**解決方法:**
1. ファイル形式がMP4か確認
2. ファイルサイズが2GB以下か確認
3. ブラウザをリロード（F5キー）
4. 別のブラウザで試す

### 処理が進まない

**症状:** 「文字起こし中」のまま長時間経過

**解決方法:**
1. ページをリロード（自動更新されます）
2. 30分以上経過しても変わらない場合は管理者に連絡
3. ジョブIDをメモしておく

### ログインできない

**症状:** メールアドレスとパスワードを入力してもログインできない

**解決方法:**
1. パスワードが正しいか確認（大文字・小文字を区別）
2. メールアドレスが正しいか確認
3. アカウント確認が完了しているか確認
4. パスワードを忘れた場合は、管理者に連絡

### 議事録が表示されない

**症状:** 「完了」になっているのに議事録が表示されない

**解決方法:**
1. ページをリロード
2. ブラウザのキャッシュをクリア
3. 別のブラウザで試す
4. 問題が続く場合は管理者に連絡

### ダウンロードできない

**症状:** ダウンロードボタンを押しても何も起こらない

**解決方法:**
1. ブラウザのポップアップブロックを確認
2. ダウンロードフォルダの容量を確認
3. 別のブラウザで試す

## 使用上の注意

### セキュリティ

- パスワードは他人と共有しないでください
- 公共のコンピュータを使用する場合は、必ずログアウトしてください
- 機密情報を含む会議の録音は、組織のセキュリティポリシーに従ってください

### データの取り扱い

- アップロードしたファイルは自動的に削除されます（7日後）
- 重要な議事録は必ずダウンロードして保存してください
- 議事録は90日後に自動削除されます

### 推奨事項

- 定期的にパスワードを変更してください
- 重要な会議の議事録は複数の場所にバックアップしてください
- 音声品質の良い録音機器を使用してください
