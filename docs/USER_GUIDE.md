## 概要

このアプリケーションは、会議の録音・録画ファイルをアップロードするだけで、自動的に議事録を生成します。

### できること

- 🎤 **音声・動画ファイルのアップロード** - MP4形式の会議録音/録画をアップロード
- 📝 **自動文字起こし** - Amazon Transcribeで音声を自動的にテキスト化
- 🤖 **AI議事録生成** - Amazon Bedrock（Claude 3.5 Sonnet v2）が議事録を自動作成
- 📊 **構造化された議事録** - 要約、トピック、決定事項、アクションアイテムを整理
- ✏️ **議事録の編集** - トピックの追加・編集・削除が可能
- 🔍 **AI検索機能** - 自然言語で議事録を検索
- 💬 **チャットQ&A** - 議事録の内容について質問できる
- 💾 **ダウンロード** - Markdown形式でダウンロード可能

### 対応ファイル形式

- **形式**: MP4
- **最大サイズ**: 2GB
- **推奨**: 音声が明瞭な録音・録画ファイル

### 技術スタック

- **フロントエンド**: Next.js 14 (React 18) + TypeScript
- **バックエンド**: AWS Lambda (Node.js)
- **認証**: Amazon Cognito（管理者承認制）
- **文字起こし**: Amazon Transcribe
- **AI生成**: Amazon Bedrock (Claude 3.5 Sonnet v2)
- **データベース**: Amazon DynamoDB
- **ストレージ**: Amazon S3
- **ホスティング**: AWS Amplify Hosting

## 議事録の作成

### ステップ1: ファイルのアップロード

1. ログイン後、「新規アップロード」ボタンをクリック
2. 「ファイルを選択」をクリックして、MP4ファイルを選択
   - または、ファイルをドラッグ&ドロップ
3. 「アップロード開始」をクリック

**ヒント:**
- ファイルサイズが大きい場合、アップロードに時間がかかります
- ドラッグ&ドロップでも簡単にアップロードできます

### ステップ2: 処理の待機

アップロード後、以下の処理が自動的に実行されます：

```
1. アップロード完了 ✅
   ↓
2. 文字起こし中 🎤 (数分～数十分)
   ↓
3. 議事録生成中 📝 (1～2分)
   ↓
4. 完了 ✅
```

**処理時間の目安:**
- 10分の会議: 約5～10分
- 30分の会議: 約15～30分
- 1時間の会議: 約30～60分

**注意:**
- ページを閉じても処理は継続されます
- 処理状況は「ジョブ一覧」から確認できます

### ステップ3: 進捗確認

1. 「ジョブ一覧」ページで処理状況を確認
2. ステータスが「完了」になるまで待機
3. 自動更新されるため、ページを開いたままにしておくと便利です

## 議事録の確認

### 議事録の表示

1. 「ジョブ一覧」から完了したジョブをクリック
2. 「議事録を表示」ボタンをクリック
3. 生成された議事録が表示されます

### 議事録の構成

生成される議事録には以下の情報が含まれます：

#### 1. 会議情報
- ジョブID
- ファイル名
- 処理日時

#### 2. 概要（Summary）
会議全体の簡潔なまとめ（2～3文程度）。独立したセクションカードとして表示されます。

#### 3. 議事内容（Agenda Items）【メイン構造】
会議で議論された各論点（議題）ごとに、独立したセクションカード「💬 議事内容」として表示されます。各論点はインジゴ色のボーダーラインで区切られ、以下の情報が構造化されます：

- **論点（Issue）**: 「論点N：XXXはどうするか？」形式で議論のテーマを表示
- **【内容】（Discussion）**: 各発言者の発言を記録
  - 発言者名：発言内容
- **【結論】（Conclusion）**: 緑色の背景で強調表示された議論の結論
- **【ネクスト論点】（Next Issues）**: この議論から派生した次の論点（箇条書き）
- **【ネクストアクション】（Next Actions）**: この論点に関するアクションアイテム
  - 担当者：アクション内容
  - 期限（オレンジ色で表示、MM/DD形式、明示されている場合）

各論点は左側にインジゴ色のボーダーラインで視覚的に区切られ、見やすく構造化されています。

#### 4. トピック別詳細（Topics）【後方互換性】
会議で議論された主要なテーマ（2～6個）
- トピックのタイトル
- 詳細説明

> **注意:** この項目は後方互換性のために残されています。新しい議事録では「論点ごとの議事録」がメインの構造として使用されます。

#### 5. 決定事項（Decisions）【後方互換性】
会議で決定された重要な事項
- 決定内容の詳細説明
- タイムスタンプ（該当箇所）

> **注意:** 新しい議事録では、決定事項は各論点の「結論」フィールドに含まれます。

#### 6. ネクストアクション（Next Actions）【後方互換性】
今後実施すべきアクションアイテム
- アクションの具体的な説明
- 担当者（明示されている場合）
- 期限（明示されている場合）
- タイムスタンプ（該当箇所）

> **注意:** 新しい議事録では、ネクストアクションは各論点の「ネクストアクション」フィールドに含まれます。

### 議事録の編集

議事録の概要（Summary）は編集可能です：

1. 議事録表示画面で「編集」ボタンをクリック
2. 概要テキストを編集
3. 「保存」ボタンをクリックして変更を保存

> **注意:** 議事内容（Agenda Items）セクションは閲覧専用です。概要とトピック別詳細（後方互換性モード時）のみ編集できます。

### AI検索機能

議事録一覧ページから自然言語で検索できます：

1. 「議事録一覧」ページにアクセス
2. 検索ボックスに質問を入力（例：「予算について話し合った会議は？」）
3. 「AI検索」ボタンをクリック
4. 関連する議事録が表示されます

### チャットQ&A機能

個別の議事録について質問できます：

1. 議事録表示画面で「チャット」ボタンをクリック
2. 質問を入力（例：「次のアクションアイテムは何ですか？」）
3. AIが議事録の内容に基づいて回答します

### 議事録のダウンロード

1. 議事録表示画面で「ダウンロード」ボタンをクリック
2. Markdown形式（.md）でダウンロードされます
3. テキストエディタやMarkdownビューアで開けます

**ダウンロードしたファイルの活用方法:**
- Notion、Confluence、Slackなどに貼り付け
- Word、Googleドキュメントで編集
- GitHubのREADMEとして使用

## よくある質問

### Q1. どのような会議に適していますか？

**A:** 以下のような会議に最適です：
- 定例会議
- プロジェクト会議
- 打ち合わせ
- ブレインストーミング
- 研修・セミナー

**注意:** 機密性の高い会議の場合は、セキュリティポリシーを確認してください。

### Q2. 音声品質の要件は？

**A:** 以下の条件で最良の結果が得られます：
- ✅ 明瞭な音声
- ✅ 背景ノイズが少ない
- ✅ 話者が明確に発音している
- ❌ 複数人が同時に話している（精度が下がる）
- ❌ 音量が小さすぎる

### Q3. 日本語以外の言語に対応していますか？

**A:** 現在は日本語のみ対応しています。

### Q4. 生成された議事録を編集できますか？

**A:** 概要（Summary）セクションは編集可能です。「編集」ボタンをクリックして概要テキストを変更し、保存できます。議事内容（Agenda Items）セクションは閲覧専用で表示されます。ダウンロード後にお好みのエディタでさらに編集することも可能です。

### Q5. AI検索機能とチャットQ&A機能について教えてください。

**A:** 
- **AI検索機能**: 議事録一覧ページから自然言語で検索できます。例えば「予算について話し合った会議は？」と入力すると、関連する議事録が表示されます。
- **チャットQ&A機能**: 個別の議事録表示画面で「チャット」ボタンをクリックすると、その議事録の内容について質問できます。AIが自動的に回答します。

### Q6. ファイルはどのくらい保存されますか？

**A:** 
- **入力ファイル（動画）**: 7日間
- **議事録**: 90日間

期限を過ぎると自動的に削除されます。重要な議事録は必ずダウンロードしてください。

### Q7. 複数のファイルを同時にアップロードできますか？

**A:** 現在は1つずつのアップロードのみ対応しています。

### Q8. 処理が失敗した場合は？

**A:** 以下を確認してください：
- ファイル形式がMP4か
- ファイルサイズが2GB以下か
- 音声が含まれているか

問題が解決しない場合は、管理者に連絡してください。

### Q9. コストはかかりますか？

**A:** 使用量に応じて以下のコストが発生します：
- 文字起こし（Transcribe）: 約$0.024/分
- AI議事録生成（Bedrock）: 約$0.05～0.10/会議
- AI検索・チャット（Bedrock）: 約$0.01～0.03/クエリ

詳細は管理者にお問い合わせください。

### Q10. どのようなセキュリティ対策がされていますか？

**A:** 以下のセキュリティ対策を実施しています：
- **IP制限**: VPN接続が必要
- **認証**: Amazon Cognito（管理者承認制）
- **データ暗号化**: S3とDynamoDBで保管時暗号化
- **自動削除**: 入力ファイル7日、議事録90日で自動削除
- **アクセス制御**: ユーザーは自分のデータのみアクセス可能

### Q11. 議事録の精度を上げるには？

**A:** 以下のポイントに注意してください：
- 明瞭な音声で録音する
- 背景ノイズを最小限にする
- 話者が明確に発音する
- 複数人が同時に話さないようにする
- マイクの近くで話す
- 会議の冒頭で参加者名を明示する

## トラブルシューティング

### アプリケーションにアクセスできない

**症状:** URLにアクセスしても「接続できません」「アクセスが拒否されました」と表示される

**解決方法:**
1. **ジールのVPNに接続しているか確認**（最も多い原因）
2. VPN接続が確立されているか確認
3. VPN接続を一度切断して再接続
4. ブラウザのキャッシュをクリア
5. 別のブラウザで試す
6. VPN接続方法が不明な場合は、IT部門に連絡

**重要:** このアプリケーションはIP制限がかかっているため、VPN接続なしではアクセスできません。

### アップロードできない

**症状:** ファイルを選択してもアップロードボタンが押せない

**解決方法:**
1. ファイル形式がMP4か確認
2. ファイルサイズが2GB以下か確認
3. ブラウザをリロード（F5キー）
4. 別のブラウザで試す

### 処理が進まない

**症状:** 「文字起こし中」のまま長時間経過

**解決方法:**
1. ページをリロード（自動更新されます）
2. 30分以上経過しても変わらない場合は管理者に連絡
3. ジョブIDをメモしておく

### ログインできない

**症状:** メールアドレスとパスワードを入力してもログインできない

**解決方法:**
1. パスワードが正しいか確認（大文字・小文字を区別）
2. メールアドレスが正しいか確認
3. アカウント確認が完了しているか確認
4. パスワードを忘れた場合は、「パスワードを忘れた場合」リンクからリセット

### 議事録が表示されない

**症状:** 「完了」になっているのに議事録が表示されない

**解決方法:**
1. ページをリロード
2. ブラウザのキャッシュをクリア
3. 別のブラウザで試す
4. 問題が続く場合は管理者に連絡

### ダウンロードできない

**症状:** ダウンロードボタンを押しても何も起こらない

**解決方法:**
1. ブラウザのポップアップブロックを確認
2. ダウンロードフォルダの容量を確認
3. 別のブラウザで試す

### AI検索が機能しない

**症状:** AI検索ボタンをクリックしても結果が表示されない

**解決方法:**
1. 検索キーワードが適切か確認
2. ページをリロード
3. 別のキーワードで試す
4. 問題が続く場合は管理者に連絡

### チャットQ&Aが応答しない

**症状:** チャットに質問を送信しても回答が返ってこない

**解決方法:**
1. インターネット接続を確認
2. ページをリロード
3. 別の質問を試す
4. 問題が続く場合は管理者に連絡
